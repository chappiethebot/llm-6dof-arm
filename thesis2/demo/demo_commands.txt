# EVERY LINE IS A VERBATIM ROW OF data/seen_v2.jsonl. No held-out command
# appears here, and none was written by hand: each was looked up in seen_v2 and
# copied with its expectation. seen_v2 is the demo/exemplar split, not a test
# split. thesis2/demo/smoke_parsers.py re-checks both properties at startup.
#
# Coverage, by construction, in exactly 10 commands:
#   all 7 verbs       pick_place, move_to, fetch, hold, inspect, stop, reject
#   grid cells        grid_A1 via pick_place, grid_A2 via move_to
#   container         box_3
#   runtime symbols   max_reach AND nearest_free_cell
#   an impossible one "unscrew the cap off the bottle" -> reject
#
# Ten is the minimum that covers all of it: five verbs carry no location
# (fetch, hold, inspect, stop, reject), so the four location families have to
# fit in the remaining five commands.
#
# Format: command, TAB, the seen_v2 expectation as JSON. The runners read
# column 1 and use column 2 only to report whether the parser agreed with the
# dataset row.
