## Ensemble wiring

One worker in the `thesis` env, no helper process (thesis2 definition, `arms._ensemble`, METHODS_NOTES item 8), run online per command:

1. `classifier:distilbert` (V5 cell, CPU, single-threaded) and `ollama:qwen2.5-3b-lora` zero_shot, both through `llm/pipeline.run_once` with the V5 legend;
2. if they agree on (action, target, location): the classifier's object;
3. otherwise `openai:gpt-4o-mini` rag x 5 (one retrieval, the V5 Retriever), every call through `common.RetryingClient` (`with_retries`); majority vote over the canonical prediction, a tie to the earliest repeat, a failed repeat votes `{}`.

The whole command (all of the above) is one timed call. `extra`: `escalated`, `cloud_calls` (0 or 5), `retries`. The raw output stores every component's raw text as JSON. Model load = classifier weights + Ollama keep-alive load of qwen2.5-3b-lora + the Retriever.

## Protocol (every system)

Unload all (Ollama keep_alive=0, previous worker ended) -> thermal gate (GPU <= 50 C, poll 1 s, max 10 min) -> idle window (300 s, nothing loaded) when the last one ended > 45 min ago -> `modelload` (worker load, timed) -> `loadedidle` 60 s (local) -> per test set: `warmup` (commands 0-2) -> thermal gate again (<= 50 C, model resident) -> `load` (shuffled passes, seed 20260827 + pass + run index (0 = v3, 1 = v4c), >= 1 pass and >= 300 s, pass in progress finished; cloud: 5 repeats per command) -> `cooldown` 60 s -> files -> after the worker exits cleanly, the runs.csv rows.

## Decisions and definitions to check

- **Idle refresh at 45 min, not 60.** verify_campaign.py requires the idle window to be <= 60 min old at the system's held_out_v3 load start; thermal gate + model load + 60 s loaded idle come in between, so a new window is taken when the last one is > 45 min old.
- **Second thermal gate, after the warm-up.** The smoke run showed the 3 warm-up calls of lora_greedy heating the GPU from 45 to 65 C in 3 s, so its load started at 57 C and verify_campaign.py (start <= 51 C) failed. The parent now waits for <= 50 C between warm-up and load (model resident, phase `between`); the wait is written in `notes`.
- **A8/A10/A12** are loaded by importing their thesis2 scripts with `--limit 3 --outdir <temp dir>`; `model_load_s` includes that 3-command decode (written in `notes`). A10/A12 then cache the token prefix common to each test set's 217 prompts, as their thesis2 runs did. `first_rejection_field` uses A11's `regions()` (taken from the file without running it), after the call's timing ends.
- **t_infer** = first start to last end of the wrapped model calls: classifier/net `forward`, Qwen2/T5 `forward` and `generate`, SentenceTransformer `encode`, sklearn `transform`/`predict`, `OllamaClient/OpenAIClient/DistilBertClassifierClient.complete`, OpenAI `chat.completions.create`. rules_*: no model call, so t_infer = the whole call.
- **Confidence**: classifiers = product of the verb, target and location heads' max softmax (factorized: location = the weakest factor, as arms.py defines it; captured logits, computed after timing). Empty for LLMs, knn_minilm and rules.
- **Tokens**: Ollama `prompt_eval_count`/`eval_count` (eval_count includes the thinking tokens); deepseek-r1 `tokens_thinking` = the trace re-tokenised with bench/backfill_tokens_v5's DeepSeek vocabulary; OpenAI `usage`; transformers from the input/output ids. Ollama `ttft_ms` = server total_duration - eval_duration; transformers `ttft_ms` = call start to the start of the LLM's second forward pass (flant5: the T5 forward); empty for A8/A10/A12 (their first token comes out of a verifier pass).
- **Failed calls**: an exception or a model_error/prompt_error stage is written to `error` and scored wrong. extract_failed / schema_failed are not errors (wrong answers, `valid_json` 0).
- **Ollama**: the server must run with OLLAMA_MODELS=D:\LLM and OLLAMA_MAX_LOADED_MODELS=1 (checked in the user/machine environment, models checked on the server); version and every digest go into machine.json, the digest into `model_sha256`. num_ctx 4096, temperature 0.0 (as recorded), no num_predict.
- **HF offline**: workers run with HF_HUB_OFFLINE=1 and TRANSFORMERS_OFFLINE=1, as the thesis2 energy stage.
